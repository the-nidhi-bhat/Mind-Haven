# Mindful Haven 🌿

Mindful Haven is a mobile-friendly wellness and mental health support web app designed to help users reflect, relax, and build healthier routines in a calm and supportive environment.

The platform brings together mood tracking, journaling, guided breathing, yoga, meditation, mindfulness games, positivity tools, and crisis support resources in one place.

---

## ✨ Features

### Wellness & Self-Care Tools
- Mood tracker with daily check-ins and emotional insights
- Private journal and worry jar for reflection and release
- Guided meditation, yoga, and breathing exercises
- Music, focus, and relaxation experiences for calm and sleep
- Light games and positivity activities for distraction and grounding

### Support & Guidance
- Crisis support page with emergency and helpline resources
- Counselor and professional support links
- AI chatbot for supportive conversations and guidance
- Journey dashboard that connects various wellness tools into one experience

### Personal Experience
- Clean, calming interface designed for mobile use
- Theme toggle for light and dark modes
- Local progress tracking and saved user preferences
- Simple sign-in flow for a more personal experience

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone <https://github.com/the-nidhi-bhat/Mind-Haven>
   ```

2. Open the project folder:
   ```bash
   cd "Mind haven  mobile"
   ```

3. Run the app locally:
   - Open [index.html](index.html) in your browser, or
   - Use a simple local server such as:
   ```bash
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000`.
